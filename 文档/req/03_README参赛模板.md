## 填写须知（交稿前删掉本节）

这份 README 是给评委看的，他会在 10 分钟内：clone 仓库 → 按你写的命令跑 → 判断能不能用。

所以规则只有四条：

1. 所有 <尖括号> 都是占位，必须换成你自己的真实内容。留下尖括号等于没写。
2. 所有数字（版本号、耗时、条目数）必须你亲手跑出来的。不能估，不能抄别人的电脑。
3. 没做过的功能不要写"已实现"。没验证的步骤不要写进"复现流程"。宁可写"未实现"。
4. 命令必须能复制粘贴直接执行。带 <你的路径> 这种命令，评委会卡住。

做不到的条目，写"未验证：<原因>"，比编一个好看。
